## 常用函数
### 变换函数
绕x y z轴旋转的旋转矩阵（单位为度）：
```matlab
rotx();
roty();
rotz();
```
绕x y z轴旋转的变换矩阵（单位为度）：
```matlab
rotx();
roty();
rotz();
```
位移转化为变换矩阵：
```matlab
transl();
```
旋转矩阵↔变换矩阵：
```matlab
t2r();
r2t();
```
### 拟合函数
五次多项式插值：
```matlab
tpoly()
```
e.g.
```matlab
t = linspace(0,2,51);
[P,dP,ddP] = tpoly(0,3,t);
```

混合曲线插值：

lspb();

### 轨迹规划
多维轨迹规划（空间两点之间规划）：
```matlab
t = linspace(0,2,51);
[P,dP,ddP] = mtraj(@tpoly,[0,0],[3,4],t);
```

多维多段规划（空间两点之间，要经过多个确定点）：
```matlab
wp=[0,0;3,4;1,2];
P1=mstraj(wp,[],[2,1],[],0.04,0)
P2=mstraj(wp,[],[2,1],[],0.04,0.5)
```

## 正运动学解算
1. 定义D-H参数、机械臂限幅等参数-L
2. 按机械臂类定义变量-SerialLink
3. 进行正运动学变换-transl()
4. 展示-plot()

给定路径点\xrightarrow{插值,轨迹规划}路径\xrightarrow{transl}变换矩阵\xrightarrow{逆运动学解算}角度
$$
MATLAB中现成的路径规划函数：
- trinterp()
- ctraj()
