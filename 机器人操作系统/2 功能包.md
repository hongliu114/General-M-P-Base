## ROS2的层次架构
![[机器人操作系统/assets/Pasted image 20251210141302.png]]
- **工作空间**： 是开发ROS项目的顶层目录，包含所有功能包、编译文件和安装文件。
    
- **功能包**： 是工作空间中的基本功能单元，对应一个特定功能的文件夹）、。一个工作空间可以包含多个功能包。
    
- **节点**： 是功能包中可执行的进程。一个功能包可以包含多个节点，每个节点负责完成一个具体的任务。
## 工作空间的结构
- src/： 源代码空间。用户在这里创建和存放所有功能包的源代码。
- build/： 编译空间。colcon工具存储缓存信息、配置参数和中间编译文件的地方。
- install/： 安装空间。构建成功后，生成的可执行文件、库文件和脚本都会安装到此目录。
- log/： 日志空间。存储构建过程中的日志信息。

常用命令：
```shell
新建工作空间目录
mkdir -p ./ros_workspace/src

构建功能包
colcon build
构建过程中，当前目录下会产生build、install和log目录
	符号链接构建（用路径符号代替实体文件）：
	colcon build --symlink-install
	
	只构建指定包：
	colcon build --packages-select <package_name>
	构建指定包及其相关包：
	colcon build --packages-up-to <package_name>
```
## 功能包
- python功能包：以py文件实现节点功能
- c++功能包：以cpp文件实现节点功能
### python功能包
- 创建功能包
  `ros2 pkg create --build-type ament_python --license Apache-2.0 <package_name>`
- 创建并编写py模块代码
  `touch hello.py`
  *编写代码*
- 设置setup.py
  添加终端脚本(console_scripts)：
  `'hello_cr = py_hello_ros.hello:main'`
  hello_cr为ros2指令中的run指令脚本名，py_hello_ros,hello,main分别是功能包名、模块名、函数名
- 构建功能包
  `colcon build`
- 运行程序
  `ros2 run py_hello_ros hello_cr`
	- 可能遇到环境变量设置问题

> [!note] 环境变量设置问题
> 1. 临时处理
> `source ~/Desktop/ros_workspace/install/setup.bash`
> 2. 永久设置
> `echo "source ~/Desktop/ros_workspace/install/setup.bash" >> ~/.bashrc`
### C++功能包
- 创建功能包
  `ros2 pkg create --build-type ament_cmake --license Apache-2.0 <package_name>`
- 创建并编写C++代码
  `touch hello.cpp`
  *编写代码*
- 设置CMakeLists.txt

## 作业
> 在ROS2系统中创建工作空间并生成一个python功能包"py_yanghui_triangle"，请编写python模块文件，要求在终端运行"ros2 run py_yanghui_triangle yanghui"后，能够输出4-10行的杨辉三角形。请给出具体的操作步骤。

- 创建工作空间目录
  `mkdir –p ~/Desktop/my_ws/src`
- 在src目录中执行创建功能包
  `ros2 pkg create --build-type ament_python --license Apache-2.0 py_yanghui_triangle`
- 在生成的“py_yanghui_triangle/py_yanghui_triangle”目录中创建yanghui_triangle.py文件(文件名自定)，并编写程序：
```python
N=10
L=[[1]]

def print_list_format():
    for i in range(0,len(L)):
        print(' '*4*(len(L)-i-1),end='')
        for k in range(0,len(L[i])):
            print(f'{L[i][k]:^8}',end='')
        print()

def main():
    for i in range(1,N):
        list_temp=[1]
        for j in range(i):
            try:
                list_temp.append(L[i-1][j]+L[i-1][j+1])
            except IndexError:
                list_temp.append(L[i-1][j]+0)
        L.append(list_temp)
    print_list_format()
```
- 编辑setup.py文件
  `yanghui = py_yanghui_triangle.yanghui_triangle:main`
- （如未设置）添加环境变量-source命令
- 构建功能包`colcon build`
- 运行`ros2 run py_yanghui_triangle yanghui`
